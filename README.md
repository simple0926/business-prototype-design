# 业务原型设计 / Business Prototype Design

`business-prototype-design` · v0.4.0-preview.2 · [GitHub Releases](https://github.com/simple0926/business-prototype-design/releases) · [发行说明 / Release notes](RELEASE_NOTES.md)

## 中文

把业务材料转成可追溯的需求、角色权限、页面规格和可验收的交互原型。

适合企业软件和有复杂权限或状态的业务流程。可按需搭配阶段 Skill，包内参考文档支持缺少相应阶段 Skill 时继续推进。

1. 从 [GitHub Releases](https://github.com/simple0926/business-prototype-design/releases/tag/v0.4.0-preview.2) 的附件下载 `business-prototype-design-v0.4.0-preview.2.zip`。
2. 解压后把 `business-prototype-design/` 文件夹复制到 `~/.codex/skills/`。更新前先备份你自行改过的文件。
3. 在 Codex 里输入 `$business-prototype-design`，附上你的目标、已有材料和交付要求。

实际业务流程和浏览器表现须在各项目中验证。生成单文件和运行相应脚本需要 Node.js 与 Python 3。

## English

Turns business evidence into traceable requirements, role permissions, page specs, and reviewable interactive prototypes.

Use it for business software with complex permissions or states. Optional stage skills can be installed separately. Included references support a fallback workflow.

1. Download the attached `business-prototype-design-v0.4.0-preview.2.zip` from [GitHub Releases](https://github.com/simple0926/business-prototype-design/releases/tag/v0.4.0-preview.2).
2. Extract and copy the `business-prototype-design/` folder to `~/.codex/skills/`. Back up any local customizations before updating.
3. In Codex, invoke `$business-prototype-design` with your goal, available inputs, and expected deliverables.

Verify actual workflows and browser behavior per project. Building the standalone file and running the corresponding tools requires Node.js and Python 3.
