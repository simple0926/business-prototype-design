# 业务原型设计 / Business Prototype Design v0.4.0-preview.2

## 中文

预览版新增证据路径约束及离线 HTML 检查。验收记录明确覆盖主流程、异常、越权、真实浏览器及断网。随包提供交付模板和校验脚本。

实际业务流程和浏览器表现须在各项目中验证。生成单文件和运行相应脚本需要 Node.js 与 Python 3。

请选择 Release 附件里的 `business-prototype-design-v0.4.0-preview.2.zip` 安装。

## English

This preview strengthens evidence path controls and offline HTML checks. Acceptance records cover the main flow, exceptions, permission boundaries, a real browser run, and offline operation. Templates and validation scripts are included.

Verify actual workflows and browser behavior per project. Building the standalone file and running the corresponding tools requires Node.js and Python 3.

Install using the attached `business-prototype-design-v0.4.0-preview.2.zip` from the release.
